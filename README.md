# Days Until You Turn 25 ⏳🎉

**Calculate how much time I have left before I hit 25 - grind hard bro!!**

This sleek countdown timer shows you exactly how many days, hours, minutes, and seconds remain until your 25th birthday. Perfect for staying motivated and making every moment count before the big 2-5! Features inspirational quotes, dark/light theme toggle, and social sharing capabilities.

![Days Until 25 Preview](og.png)

## ✨ Features

- **Real-time countdown** - Live timer updating every second
- **Dark/Light theme** - Toggle between themes for comfortable viewing
- **Motivational quotes** - Random inspiring quotes to keep you motivated
- **Social sharing** - Share your countdown on Twitter and LinkedIn
- **Screenshot download** - Save your countdown as a PNG image
- **Mobile responsive** - Works perfectly on all devices
- **Clean design** - Beautiful, modern interface

## 🚀 How to Use

1. **Enter your birth date** using the interactive date picker
2. **Watch the countdown** update in real-time showing days, hours, minutes, and seconds
3. **Get inspired** with motivational quotes that appear with your countdown
4. **Share your progress** with friends on social media
5. **Download screenshots** to save memorable milestones

## 🎯 Motivation

Your twenties are crucial years for building your future. Whether you're working towards career goals, personal development, or life milestones, this countdown serves as a daily reminder to make the most of your time. Every second counts - use them wisely!

## 🛠️ Getting Started

Want to customize this for yourself or contribute? Here's how:

1. **Fork** this repository to your GitHub account
2. **Clone** it locally:

   ```bash
   git clone https://github.com/your-username/Days_Until_25.git
   cd Days_Until_25
   ```

3. **Open** `index.html` in your browser or set up a local server
4. **Customize** the quotes, styling, or add new features
5. **Deploy** to your favorite hosting platform (Vercel, Netlify, etc.)
